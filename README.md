# DocuMaster

All-in-one document management platform created by Hamdan.

## Features

### Free Tools
- **PDF Merge** - Combine multiple PDFs into one document
- **PDF Split** - Extract pages or split PDFs into multiple files
- **PDF Compress** - Reduce file size while maintaining quality
- **Word to PDF** - Convert Word documents to PDF format
- **Image Converter** - Convert images between PNG, JPG, and WebP
- **OCR Scanner** - Extract text from images and scanned documents
- **Digital Signature** - Add signatures to PDF documents
- **PDF Format** - Extract pages from PDFs

### Premium Features ($9.99/month)
- Unlimited operations
- 100 MB file size limit
- No ads
- Priority support
- Cloud storage (5 GB)
- Custom watermarks

### Team Features ($29.99/month)
- Everything in Premium
- Up to 10 team members
- Real-time collaboration
- Document approval workflows
- Team analytics dashboard
- API access
- Advanced security

## Technology Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, RLS)
- **PDF Processing**: pdf-lib
- **OCR**: Tesseract.js
- **Build Tool**: Vite

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
